# Plateforme Business Intelligence E-commerce

Projet de Business Intelligence visant à concevoir un système décisionnel
complet pour analyser les performances commerciales et logistiques
d’une marketplace e-commerce.

## Objectif du projet

L’objectif est de construire une chaîne BI complète :

Données brutes
→ Contrôle de la qualité des données
→ ETL
→ Data Warehouse PostgreSQL
→ Analyses SQL
→ Power BI
→ Indicateurs de performance
→ Aide à la décision

## Technologies prévues

- Python
- Pandas
- PostgreSQL
- SQL
- Power BI
- DAX
- Git

## Principales analyses

Le système permettra notamment d’analyser :

- les performances commerciales ;
- l’évolution du chiffre d’affaires ;
- les performances des produits et des catégories ;
- les performances géographiques ;
- les performances des vendeurs ;
- les délais de livraison ;
- les retards de livraison ;
- la satisfaction des clients.

## Architecture générale

Données CSV
→ Nettoyage et transformation avec Python/Pandas
→ Data Warehouse PostgreSQL
→ Analyses SQL
→ Power BI
→ KPI et tableaux de bord
→ Aide à la décision

## État du projet

Projet en cours de développement.
